Featured Projects

SCARA Robot

A fully functional SCARA robotic arm prototype built for the Cracow University of Technology science club. Features comprehensive manual and automatic control through a custom desktop application, including real-time dynamics control, trajectory programming, and a gripper module.

Language: Java (Processing), C++ (Arduino) Hardware: Stepper Motors, Gripper Features: Real-time control, Trajectory memory Control Mode: Manual & Auto

GeoTracker&Notify

GeoTracker&Notify is a desktop application that goes beyond standard to-do lists by triggering reminders based on your real-time geographic location. It combines a robust PyQt5 interface with a background Flask server to handle geolocation data, ensuring you never forget a task when you arrive at a specific destination.

Language: Python, Javascript Backend Logic: Flask Frontend: PyQt5 (GUI) Database: SQLite, SQLAlchemy (ORM) API: OpenCage Data DataBase migration tool: Alembic

AI EmailAgent

AI_EmailAgent is an intelligent, CLI-based Executive Email Assistant designed to help you manage your Gmail inbox efficiently. Operating under the persona of a concise assistant, it combines the Gemini API with direct Gmail integration to proactively summarize threads, sort incoming mail, and draft contextual responses.

Language: Python 3.x AI Engine: Google GenAI SDK (Gemini) Email Integration: Google Workspace Gmail API Architecture: Custom Tool Calling
