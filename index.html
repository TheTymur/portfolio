Featured Projects

Wizards Wars

Wizards War is a 2D turn-based battle game developed using Python and Pygame. The game pits two players against each other in an epic magical showdown. Players assume the roles of wizards, each equipped with health, mana, and a set of powerful spells. The goal is to outmaneuver and outlast your opponent by strategically managing resources, casting spells, and exploiting opportunities to claim victory.

Language: Python Library: Pygame Architecture: Modular State Management: Global variables and standard control flow

GeoTracker&Notify

GeoTracker&Notify is a desktop application that goes beyond standard to-do lists by triggering reminders based on your real-time geographic location. It combines a robust PyQt5 interface with a background Flask server to handle geolocation data, ensuring you never forget a task when you arrive at a specific destination.

Language: Python, Javascript Backend Logic: Flask Frontend: PyQt5 (GUI) Database: SQLite, SQLAlchemy (ORM) API: OpenCage Data DataBase migration tool: Alembic
